# Dharvi Prajapati — Portfolio

Static portfolio site. No build step needed.

## Structure

- `index.html` — the whole site (layout, styles and scripts)
- `assets/` — all images and project posters the page loads

Keep `index.html` and `assets/` together in the same folder.

## Hosting on GitHub Pages

1. Create a new repository on GitHub (for example `portfolio`).
2. Upload the contents of this folder (`index.html` and `assets/`) to the repository root and commit.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Local preview

Open `index.html` in a browser. Everything works offline, except the Google Fonts request.
